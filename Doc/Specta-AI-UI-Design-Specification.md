# Specta AI 平台 UI 设计规范文档

## 1. 设计概述

本文档整合了 Manus 和 AnyGen Canvas 两个参考设计的最佳实践，为 Specta AI 平台定义统一的视觉和交互设计规范。

### 1.1 设计理念

- **信息层级清晰**：采用 TPAOR 框架的可视化呈现（思考→规划→行动→观察→回复）
- **渐进式披露**：复杂信息通过可折叠区块逐步展示
- **用户控制感**：关键节点暂停等待用户确认
- **实时反馈**：执行过程透明可见

```

│ ● 思考                                              ▼ 折叠  │
```

## 9. 交互设计规范

### 9.1 TPAOR 执行流程交互

```
用户输入品牌名称
        │
        ▼
┌───────────────────┐
│ 【思考】展开显示   │ ← 自动展开，1秒后折叠
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 【规划】展开显示   │ ← 显示执行计划
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 【行动】执行中     │ ← 显示进度指示器
│  - A1 运行中...   │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 【观察】结果展示   │ ← 显示执行结果摘要
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 【回复】用户确认   │ ← 暂停，等待用户选择
│  [继续] [跳过]    │
└───────────────────┘
```

### 9.2 折叠/展开动画

- 动画时长：200ms
- 缓动函数：ease-out
- 展开时内容淡入
- 折叠时内容淡出

### 9.3 加载状态

**骨架屏：**
- 用于初始加载
- 灰色渐变动画

**进度条：**
- 用于 Agent 执行
- 显示百分比 + 当前步骤

**旋转图标：**
- 用于短时等待
- 品牌色旋转动画

### 9.4 用户确认交互

1. 确认卡片出现时，Chat 窗口自动滚动到底部
2. 按钮支持键盘操作（Enter 确认，Esc 取消）
3. 选择后按钮变为禁用状态，显示「已选择」
4. 支持撤销操作（5秒内）

## 10. 动效规范

### 10.1 过渡动画

```css
/* 标准过渡 */
--transition-fast: 150ms ease-out;
--transition-normal: 200ms ease-out;
--transition-slow: 300ms ease-out;

/* 弹性动画 */
--transition-bounce: 300ms cubic-bezier(0.68, -0.55, 0.265, 1.55);
```

### 10.2 微交互

| 交互 | 动效 |
|------|------|
| 按钮悬停 | 背景色渐变 + 轻微上移 (translateY -1px) |
| 卡片悬停 | 边框高亮 + 阴影加深 |
| 折叠展开 | 高度动画 + 内容淡入淡出 |
| 进度更新 | 数字滚动 + 进度条填充 |
| 成功反馈 | 绿色闪烁 + 勾选图标弹入 |

## 11. 响应式适配

### 11.1 桌面端 (≥1440px)

- 三栏完整显示
- Canvas 默认展开
- 导航栏完整显示

### 11.2 笔记本 (1024-1439px)

- Canvas 默认折叠，点击展开
- 导航栏可折叠为图标模式
- Chat 窗口占据主要空间

### 11.3 平板 (768-1023px)

- 导航栏折叠为侧边抽屉
- Canvas 变为底部抽屉
- 单栏 Chat 为主

### 11.4 移动端 (<768px)

- 底部标签导航
- 全屏 Chat 模式
- Canvas 为独立页面

---

## 12. 无障碍设计

### 12.1 颜色对比度

- 正文文字对比度 ≥ 4.5:1
- 大标题对比度 ≥ 3:1
- 交互元素对比度 ≥ 3:1

### 12.2 键盘导航

- 所有交互元素可通过 Tab 聚焦
- 焦点状态清晰可见
- 支持 Escape 关闭弹窗

### 12.3 屏幕阅读器

- 所有图标配有 aria-label
- 动态内容使用 aria-live
- 表单元素关联 label
