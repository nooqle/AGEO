## 一、测试目标与范围

### 1.1 核心目标

验证 Specta AI 平台在**纽崔莱品牌**场景下的全链路功能完整性，确保以下五个层面的设计预期一致：

1. **Agent 层**: General ReAct Agent 的 TPAOR 编排与调度能力
2. **技术架构层**: MiniMax M2.1 Mini-Agent 架构稳定性
3. **Tool 层**: A1-A5 Tool 的功能正确性
4. **前端交互层**: Manus 风格的拟人化对话体验
5. **交互输出层**: 完整业务链路的数据输出准确性
