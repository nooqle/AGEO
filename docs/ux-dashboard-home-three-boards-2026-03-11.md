# UX 原型：Dashboard 首页三看板改版

> 角色：UX  
> 日期：2026-03-11  
> 状态：原型稿  
> 范围：仅 Dashboard 首页与三看板展开说明报告  
> 约束：不破坏 Dashboard 外的其他首页逻辑

## 1. UX 目标

用户进入 Dashboard 首页后，应立即建立这样的心智模型：

1. 提及率 = AI 有没有提到我，以及怎么评价我
2. 官网引用率 = AI 有没有把我的官网当成可信来源
3. 五维雷达 = 我当前整体强弱的形状

首页的职责是“先给判断入口”，不是“先给完整分析细节”。

## 2. 首页信息架构

```text
Dashboard 首页
  ├── 顶部标题区
  │    ├── 品牌名
  │    └── 一句话战况摘要
  ├── 三看板区域
  │    ├── 提及率看板
  │    ├── 官网引用率看板
  │    └── 五维雷达看板
  └── Monitoring 独立入口
```

## 3. 首页线框

```text
[品牌名] Dashboard
一句话摘要：当前品牌已建立部分 AI 提及，但官网引用链路仍偏弱，竞品在购买决策类问题中更占优。

[提及率看板] [官网引用率看板] [五维雷达看板]

[Monitoring 独立入口]
```

每个看板统一包含：

1. 1 个核心指标
2. 2 到 3 个辅助事实
3. 1 句判断
4. 1 个 CTA：查看说明报告

## 4. 三个看板的交互定义

### 4.1 提及率看板

#### 首页卡片

显示：

1. 品牌提及率
2. 情绪概览：正向 / 中性 / 负向
3. 提及率更高的主要竞品摘要
4. 一句话判断

#### 点击后展开说明报告

结构：

1. 顶部结论
2. 品牌被提及的问题列表
3. 每个问题的情绪与平台
4. 主要引用来源
5. 竞品对比
6. 场景归纳：品牌优势 / 竞品优势 / 品牌缺席

### 4.2 官网引用率看板

#### 首页卡片

显示：

1. 官网引用率
2. 被引用问题数
3. 被引用官网内容数
4. 一句话判断

#### 点击后展开说明报告

结构：

1. 顶部结论
2. 哪些问题引用了官网
3. 引用了哪些官网内容
4. 来自哪些页面 / 标题
5. 未引用官网而引用第三方的问题
6. AICE 占位区

### 4.3 五维雷达看板

#### 首页卡片

显示：

1. 五维雷达图
2. 最大优势维度
3. 最大短板维度
4. 一句话判断

#### 点击后展开说明报告

结构：

1. 顶部结论
2. 五维定义
3. 每一维的解释
4. 每一维的支撑证据
5. 建议动作

## 5. Monitoring 的位置

Monitoring 不混入三看板。

建议作为首页下方一个独立入口卡，承担：

1. 趋势变化
2. 告警
3. 持续监测跳转

## 6. 视觉优先级原则

首页视觉优先级应固定为：

1. 一句话摘要
2. 三个看板
3. Monitoring

首页不应再优先展示：

1. 长表格
2. 多 tab 并列
3. 大量解释文字
4. 零散风险条目

## 7. UX 结论

这次 Dashboard 首页改版的关键，不是把更多信息塞到首页，而是把首页变成三个高质量决策入口。

用户应该先点进问题，再看证据，而不是先被细节淹没。
