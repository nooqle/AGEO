参考版用"务实派/档案员/百科/叙事者"让读者 5 秒记住 4 平台差异。当前版只有"风险提示派"标签，读完即忘。

**改动方向**：
- 后端：在 `platform_profiles` 里加 `persona` 字段（性格描述 + 一句代表性原话）
- 前端：AI 档案节和平台差异节渲染 persona card

### 4.2 论证结构扁平（差距 7）

参考版四段式："原话 → 解读 → 差距类型 → 升级路径"。每段有明确职能：
- 原话：让读者看到 AI 怎么说
- 解读：点出原话里的关键矛盾
- 差距类型：给矛盾命名
- 升级路径：指明下一步

当前版两段式："状态 + 但..."。落差感和升级路径都不清晰。

**改动方向**：
- 后端：四有节每"有"的 paragraphs 改成四段式
- 前端：每"有"独立 h3 + 落差副标题

### 4.3 commercialReportCopy 绕句（差距 9）

`commercialReportCopy` 函数（`AmwayAssociationCircleDashboardViews.tsx:2776`）做这些替换：
- "不是" → "并不等同于"
- "而是" → "更接近"
- "强关联轨" → "已绑定资产"
- "贴近度" → "图谱贴近值"

本意是去政治化/去工程化，但副作用是让所有句子变绕。比如：
- 参考版："安利是一个被问才答的品牌，不是一个被主动推荐的品牌"
- 当前版："安利更像被点名才出现的品牌，并不等同于会被主动推荐的品牌"

**改动方向**：
- 后端：去掉 commercialReportCopy 的"不是→并不等同于"、"而是→更接近"替换
- 保留轨道术语替换（"强关联轨→已绑定资产"等，这些是必要的去工程化）
