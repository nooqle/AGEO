# PRD：Dashboard 首页三看板改版

> 角色：PM  
> 日期：2026-03-11  
> 状态：初稿  
> 范围：仅 Dashboard 首页与三看板展开说明报告  
> 非目标：不改 Chat、不改 Canvas 机制、不改系统其他首页、不重写 Monitoring 主逻辑

## 1. 背景与问题

当前 Dashboard 的主要问题不是“没有数据”，而是“数据没有形成判断”。

用户打开 Dashboard 后，能看到很多信息块，但难以快速回答下面三个问题：

1. 我有没有被 AI 提到，以及 AI 是怎么评价我的。
2. AI 有没有把我的官网当成可信来源。
3. 我的整体战况是强还是弱，短板在哪里。

当前页面的问题集中在：

1. 首页信息过多，但缺少结论层。
2. 模块边界不清，用户不知道应该先看哪里。
3. 细节很多，但无法快速推导出“当前最重要的动作”。

## 2. 产品目标

将 Dashboard 首页收敛为 3 个核心看板，每个看板都能点击展开为说明报告。

3 个看板分别是：

1. 提及率看板
2. 官网引用率看板
3. 五维雷达看板

Monitoring 保留为独立入口，不并入这 3 个看板。

## 3. 用户价值

### 3.1 提及率看板

用户希望知道：

1. 我的品牌被哪些问题提及了。
2. 被提及时，情绪是正向、中性还是负向。
3. 哪些竞品提及率比我高。
4. 这些竞品被哪些问题提及了，情绪如何。
5. 从这些问题进一步折射出，哪些场景是我强，哪些场景是竞品强。

### 3.2 官网引用率看板

用户希望知道：

1. 哪些问题引用了我的官网。
2. 引用了官网哪些内容。
3. 为什么这些内容容易被信任。
4. 哪些问题没有引用官网，而是引用了第三方。

### 3.3 五维雷达看板

用户希望快速知道整体强弱形状，而不是看一堆散点指标。

五个维度定义为：

1. 行业影响
2. 人群覆盖
3. 场景覆盖
4. 风险大小
5. 积极情绪大小

## 4. 首页结构

Dashboard 首页仅展示以下内容：

1. 顶部一句话战况摘要
2. 三个核心看板
3. Monitoring 独立入口

首页不再承担“完整展开所有分析模块”的职责。

## 5. 三个看板的首页展示定义

### 5.1 提及率看板

首页显示：

1. 品牌提及率
2. 高于你的主要竞品数量或名单摘要
3. 品牌被提及时的情绪概览
4. 一句话结论
5. CTA：查看说明报告

### 5.2 官网引用率看板

首页显示：

1. 官网引用率
2. 被引用问题数
3. 被引用官网内容数
4. 一句话结论
5. CTA：查看说明报告

### 5.3 五维雷达看板

首页显示：

1. 五维雷达图
2. 最大优势维度
3. 最大短板维度
4. 一句话结论
5. CTA：查看说明报告

## 6. 看板展开后的说明报告定义

### 6.1 提及率说明报告

需要回答：

1. 品牌被哪些问题提及了。
2. 每个问题中的情绪如何。
3. 竞品被哪些问题提及了。
4. 竞品情绪如何。
5. 归纳后哪些场景品牌做得好，哪些场景竞品做得更好。

### 6.2 官网引用率说明报告

需要回答：

1. 哪些问题引用了官网。
2. 引用了官网哪些内容。
3. 来自哪些页面或标题。
4. 哪些问题没有引用官网。
5. 后续 AICE 如何解释这些内容的可信度。

### 6.3 五维雷达说明报告

需要回答：

1. 每一维为什么高或低。
2. 每一维背后的证据是什么。
3. 目前最大优势是什么。
4. 目前最大短板是什么。
5. 应优先采取什么动作。

## 7. 不做什么

本次改版明确不做：

1. 不新增更多一级分析模块。
2. 不把场景、竞品争夺、风险动作继续并列铺满首页。
3. 不把 Monitoring 并进三看板。
4. 不改 Dashboard 外的其他首页逻辑。

## 8. 成功标准

上线后，用户进入 Dashboard 首页，应能在 10 秒内回答：

1. 我的品牌有没有被提到。
2. AI 有没有引用我的官网。
3. 我整体最强和最弱的维度是什么。

并且用户应能自然点击进入任一看板的说明报告，继续看证据与解释。

## 9. PM 结论

Dashboard 首页不该再是“很多 tab 的入口集合”，而应该是“3 个高信息密度判断入口”。

这次首页改版的核心不是加更多内容，而是把已有数据压缩成三个用户真正关心的问题：

1. 我被怎么提到。
2. 我的官网有没有被信。
3. 我的整体战况是什么形状。
