## 当前问题

`general_react.py` 的 `_execute_full_analysis` 是硬编码的线性流程：
```
A1 → A2 → A3 → A4 → A5
```

这违背了您的设计思路。

## 您的设计思路

General ReAct Agent 应该：

1. **A1 执行后** → 展示品牌信息 → 等待用户确认
2. **A2 执行后** → 展示画像列表 → 让用户选择 → 基于选择继续
3. **A3 有两个分支**：
   - 只有 A1 信息 → 生成基准问题
   - 有 A2 信息 → 基于用户选择的画像生成问题
4. **每个阶段都可以暂停**，等待用户确认

## 修复方案

### 1. 增强 GeneralReActAgent
- 添加状态持久化机制（保存执行状态）
- 在每个 Agent 执行后添加确认点
- 实现 A2 后的画像选择逻辑
- 实现 A3 的条件分支逻辑

### 2. 修改 _execute_full_analysis
- 改为可暂停/恢复的执行流程
- 在关键节点生成确认请求事件
- 根据用户选择决定下一步

### 3. 前端适配
- 处理确认请求事件
- 展示画像选择界面
- 支持继续/跳过/重试操作

### 4. 状态管理
- 使用 session 存储执行状态
- 支持断点续传
- 用户刷新页面后可以恢复

## 实施步骤

1. 修改 `general_react.py` - 添加确认机制和状态管理
2. 修改 `socketio_server.py` - 处理确认消息
3. 前端添加确认对话框和画像选择
4. 测试完整流程：纽崔莱 → A1 → 确认 → A2 → 选择画像 → A3 → ...
