## 修改方案：完善TPAOR序列与动效体验

### 问题分析

通过代码审查发现以下关键问题：

1. **后端TPAOR事件不完整** - `general_react_v2.py` 只发送了"思考"和"回复"阶段，缺少"规划"、"行动"、"观察"阶段的中间事件
2. **前端动画效果不足** - TPAORCard只有基础展开/折叠，缺少Manus式的流畅动效
3. **阶段图标静态** - 活跃阶段只有简单的旋转动画，缺少更丰富的视觉反馈

### 修改方案

#### Phase 1: 后端TPAOR事件完善

**文件**: `aeo-platform/backend/app/agents/general_react_v2.py`

**修改内容**:
1. 在 `_execute_decision` 方法中添加"行动"阶段事件发送
2. 在 Agent 执行完成后添加"观察"阶段事件
3. 确保每个阶段都有对应的 `tpaor_phase` 事件

**具体修改**:
- 第156-173行: 在调用 Agent 前后添加 action 和 observation 阶段事件
- 添加 `emit_action_phase()` 和 `emit_observation_phase()` 辅助方法

#### Phase 2: 前端TPAOR动画优化

**文件**: `frontend/src/components/chat/TPAORCard.tsx`

**修改内容**:
1. **阶段切换动画** - 添加阶段之间的流畅过渡效果
2. **活跃状态动效** - 使用脉冲光环效果替代简单旋转
3. **进度时间线** - 添加阶段之间的时间线指示器

**具体修改**:
- 添加 `framer-motion` 的 `layoutId` 实现流畅布局动画
- 活跃阶段添加脉冲光环动画 (box-shadow pulse)
- 阶段切换时添加滑动过渡效果

#### Phase 3: TPAORSequence状态管理优化

**文件**: `frontend/src/components/chat/TPAORSequence.tsx`

**修改内容**:
1. 优化自动折叠逻辑，确保非行动阶段1.5秒后正确折叠
2. 添加阶段完成时的视觉反馈（如完成标记动画）
3. 确保5个阶段按顺序正确显示

**具体修改**:
- 修复 `auto-collapse` 逻辑，当前有数据时才显示对应阶段
- 添加阶段完成时的打勾动画
- 优化阶段切换时的滚动定位

#### Phase 4: 图标动效增强

**文件**: `frontend/src/components/chat/TPAORCard.tsx`

**修改内容**:
1. 每个阶段图标添加独特的微动画
   - 思考: 脑图标添加"思考波纹"效果
   - 规划: 列表图标添加"逐项出现"效果
   - 行动: 闪电图标添加"闪烁"效果
   - 观察: 眼睛图标添加"眨眼"效果
   - 回复: 消息图标添加"打字"效果

### 预期效果

修改后将实现：
1. ✅ 完整的5阶段TPAOR序列（思考→规划→行动→观察→回复）
2. ✅ 非行动阶段1.5秒后自动折叠
3. ✅ 活跃阶段有独特的动态图标效果
4. ✅ 阶段切换有流畅的过渡动画
5. ✅ 清晰的时间线进度指示

### 风险与注意事项

1. 后端事件发送顺序需要严格测试，避免阶段错乱
2. 动画性能需要优化，避免过多重渲染
3. 需要确保向后兼容，旧版本事件格式仍能正常显示

### 实施顺序

1. Phase 1 (后端) → 2. Phase 2 (前端动画) → 3. Phase 3 (状态管理) → 4. Phase 4 (图标动效)
