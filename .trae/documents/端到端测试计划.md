## 端到端测试计划

### 项目架构
- **前端**: Next.js 16 + React 19 + TypeScript + Zustand (port 3000)
- **后端**: FastAPI + LangGraph + WebSocket (port 8000)
- **多Agent系统**: A1(品牌) → A2(画像) → A3(问题) → A4(抓取) → A5(报告)

### 测试文件分析
测试脚本 `e2e_test.js` 使用 Playwright 进行自动化测试：
1. 访问首页并截图
2. 进入聊天页面 `/chat/test-yazi-e2e-001`
3. 输入品牌名称"雅姿"
4. 发送消息并监听 WebSocket 响应
5. 检查页面内容并截图记录

### 测试执行步骤
1. 确保前后端服务已启动
2. 创建 `test_results` 目录存放截图
3. 运行 `node e2e_test.js`
4. 记录所有发现的问题（不修改代码）

### 关键检查点
- WebSocket 连接建立
- 用户消息发送/接收
- Agent 执行进度显示
- Canvas 内容展示
- 确认请求处理
