## 执行计划

### Step 1: 创建环境配置文件

**1.1 后端环境配置**
**文件**: `backend/.env.local.example`
- 数据库配置（SQLite/PostgreSQL）
- Redis 配置（可选）
- LLM API Keys
- 开发模式设置

**1.2 前端环境配置**
**文件**: `frontend/.env.local.example`
- API URL
- WebSocket URL

### Step 2: 创建后端核心模块

**2.1 配置模块**
**文件**: `backend/app/core/config.py`
- 支持多环境配置
- 从环境变量读取配置
- 提供默认值

**2.2 数据库模块**
**文件**: `backend/app/core/database.py`
- 支持 SQLite 和 PostgreSQL 双模式
- 自动判断数据库类型
- 创建异步引擎和会话

**2.3 缓存模块**
**文件**: `backend/app/core/cache.py`
- Redis 连接（可选）
- 内存缓存降级方案
- get/set/delete 方法

### Step 3: 创建开发脚本

**3.1 一键启动脚本**
**文件**: `scripts/dev.sh`
- 检查虚拟环境
- 检查前端依赖
- 启动后端服务（port 8000）
- 启动前端服务（port 3000）
- 信号处理（Ctrl+C 停止所有服务）

**3.2 LLM 测试脚本**
**文件**: `backend/scripts/test_llm.py`
- 测试 MiniMax 连接
- 测试 Doubao 连接
- 测试 Hunyuan 连接

### 预期产出
1. `backend/.env.local.example` - 后端环境配置模板
2. `frontend/.env.local.example` - 前端环境配置模板
3. `backend/app/core/config.py` - 配置模块
4. `backend/app/core/database.py` - 数据库模块
5. `backend/app/core/cache.py` - 缓存模块
6. `scripts/dev.sh` - 一键启动脚本
7. `backend/scripts/test_llm.py` - LLM 测试脚本

### 本地开发流程

```bash
# 1. 配置环境变量
cp backend/.env.local.example backend/.env.local
cp frontend/.env.local.example frontend/.env.local
# 编辑 .env.local 文件，填入 API Keys

# 2. 一键启动
./scripts/dev.sh

# 3. 访问
# 前端: http://localhost:3000
# 后端: http://localhost:8000
# API 文档: http://localhost:8000/docs
```
