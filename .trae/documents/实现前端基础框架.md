## 执行计划

### Step 1: 初始化 Next.js 项目

执行命令：
```bash
npx create-next-app@latest frontend --typescript --tailwind --eslint --app --src-dir
cd frontend
npm install zustand socket.io-client framer-motion @radix-ui/react-dialog @radix-ui/react-dropdown-menu @radix-ui/react-tooltip @radix-ui/react-tabs recharts lucide-react clsx tailwind-merge
```

### Step 2: 创建类型定义
**目录**: `frontend/src/types/`

- `message.ts` - 消息类型（MessageType, TPAORContent, OutputCard, ConfirmationOption, ConfirmationRequest, Message）
- `agent.ts` - Agent 类型（TPAORPhase, TPAORUpdate, ExecutionProgress, SubTask, BrowserState, OutputReady）
- `canvas.ts` - Canvas 类型（CanvasMode, CanvasContent）
- `execution.ts` - 执行状态类型（StopState, RollbackInfo）

### Step 3: 创建 Zustand 状态管理
**目录**: `frontend/src/stores/`

- `conversationStore.ts` - 对话状态（messages, isAgentTyping, isAgentExecuting, pendingConfirmation, currentTPAOR, executionProgress, browserState, stopState）
- `canvasStore.ts` - Canvas 状态（isOpen, mode, contents, activeContentIndex）

### Step 4: 创建 Hooks
**目录**: `frontend/src/hooks/`

- `useWebSocket.ts` - WebSocket 连接管理，事件监听，发送方法
- `useResponsive.ts` - 响应式布局（breakpoint, width, isMobile/Tablet/Laptop/Desktop）
- `useKeyboardShortcuts.ts` - 快捷键支持（Esc, Cmd/Ctrl+\, Cmd/Ctrl+Shift+F）

### Step 5: 创建工具库
**目录**: `frontend/src/lib/`

- `animations.ts` - Framer Motion 动画配置（transitions, messageVariants, canvasPanelVariants, chatPanelVariants, collapseVariants, cardHoverVariants, selectionCardVariants, modalVariants, overlayVariants, mobileCanvasVariants, progressVariants）
- `utils.ts` - 工具函数（cn, formatTime, formatDateTime, formatProgress, parseUserSelection, formatSelectionAsMessage, getCircledNumber, truncate）

### Step 6: 创建布局组件
**目录**: `frontend/src/components/layout/`

- `AppLayout.tsx` - 主布局组件（响应式，支持 Canvas 分屏/聚焦模式）
- `Header.tsx` - 顶部导航（Logo, 项目名称, 操作按钮）

### Step 7: 创建 API 服务
**文件**: `frontend/src/services/api.ts`

- `ApiService` 类
- 会话管理（createSession, getSession, deleteSession）
- 消息管理（getMessages, sendMessage, rollbackAfterMessage）
- 产出管理（getOutputs, getOutput, exportOutput）
- Agent 控制（stopAgent, resumeAgent, sendConfirmation）
